Put the CHROMAS network weights here: `sepia_2classes_fcn_resnet50.pth`.

They come from the CHROMAS authors' data release (Ukrow et al. 2025; Edmond, doi:10.17617/3.MJI3HA). Check the
licence there before you share the file. If this folder has no weights, the dashboard uses `model_weights/` in the
CHROMAS folder. See the README, section *Network weights*.
